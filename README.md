# Minecraft.gg
Minecraft.gg ile tarayıcında 3D blok dünyasına dal! Play’e bas, Overworld, Nether veya End’den birinde rastgele doğ. Java tarzı kontroller, kazma-yerleştirme, F5 ile üçüncü şahıs kamera ve kendi skin’ini yükleme özelliği seni bekliyor. Kurulum yok, sadece PC’de aç ve oyna. Hazırsan blokları kırmaya başla!
